## 1. 财务部组织架构与岗位职责

### 1.1 组织架构
```
集团CFO / 财务总监
 ├─ 会计核算组（总账、应收、应付、成本）
 ├─ 资金管理组（出纳、资金计划、银行关系）
 ├─ 预算分析组（预算、经营分析、管理报表）
 ├─ 税务组（纳税申报、税务筹划、发票管理）
 └─ 各子公司财务负责人
```

### 1.2 关键岗位职责
| 岗位 | 核心职责 | 不相容职务 |
|---|---|---|
| 出纳 | 现金/银行收付、日记账登记 | 不得兼管总账、稽核、会计档案 |
| 总账会计 | 凭证审核、结账、报表 | 不得直接经手货币资金 |
| 成本会计 | 成本归集、分摊、核算 | 不得兼任采购审批 |
| 税务会计 | 申报、发票、涉税合规 | 不得兼任资金支付审批 |
| 财务负责人 | 制度落地、审批、分析 | 对报表真实性负责 |

## 2. 财务核算基础规范

### 2.1 核算原则
- 执行《企业会计准则》，记账本位币为人民币
- 权责发生制、借贷记账法
- 会计期间：月度结账（次月5日前完成）、年度结账

### 2.2 凭证管理
- 原始凭证"真实、合法、完整"三要素
- 记账凭证须附原始单据，做到"一单一记、附件齐全"
- 凭证审核：制单人与审核人不得为同一人
- 错账更正：红字冲销或补充登记，严禁直接涂改、刮擦

### 2.3 结账流程（月度）
1. 出纳核对银行对账单，编制余额调节表
2. 各项计提（折旧、摊销、工资、税金）
3. 往来科目核对与清理
4. 成本结转
5. 试算平衡
6. 出具报表
7. 财务负责人复核签字

## 3. 资金管理

### 3.1 现金管理
- 库存现金限额：原则上不超过 3 日零星开支（约 5000 元）
- 严禁坐支现金、白条抵库、公款私存
- 每日盘点，做到日清月结，账实相符

### 3.2 银行存款管理
- 网银U盾、支付密钥分人保管（制单盾、复核盾分离）
- 大额支付（≥50万元）须双人复核、财务负责人审批
- 每月核对银行对账单，余额调节表由非出纳人员编制

### 3.3 资金计划
- 各部门每月25日前报次月资金计划
- 资金调度"以收定支、统筹平衡"
- 集团资金池统一归集，提高使用效率

## 4. 费用报销与审批制度

### 4.1 报销基本原则
- 真实性：业务真实发生，票据合法合规
- 合理性：标准内开支，超标需专项审批
- 及时性：费用发生后 30 日内报销，跨年度原则上不予受理

### 4.2 审批权限（示意）
| 费用金额 | 审批层级 |
|---|---|
| ≤ 2000元 | 部门负责人 → 会计审核 |
| 2000–20000元 | 部门负责人 → 财务 → 分管副总 |
| 20000–100000元 | 逐级上报 → 总经理 |
| ≥ 100000元 | 总经理 → 董事长 |

### 4.3 常见费用标准（示例）
- 差旅费：交通、住宿按职级标准执行，超标自理
- 业务招待费：事前申请、人均标准、凭票报销
- 办公用品：集中采购，部门领用登记

### 4.4 报销必备附件
- 发票（抬头、税号正确，验真）
- 审批单
- 合同/订单（如涉及）
- 付款申请单、收款方信息

## 5. 应收应付管理

### 5.1 应收账款
- 建立客户信用档案，设定信用额度与账期
- 每月出具账龄分析表
- 超期应收账款：催收责任人明确，逾期 90 天预警、180 天专项处理
- 坏账核销须经审批，账销案存

### 5.2 应付账款
- 按合同账期付款，维护供应商信用
- 付款前三单匹配：合同、入库单、发票
- 定期与供应商对账，差异及时处理

## 6. 固定资产与存货管理

### 6.1 固定资产
- 标准：单位价值 ≥ 2000元、使用年限 > 1 年
- 新增：验收、编号、建立卡片
- 折旧：按类别确定年限与残值率
- 盘点：每年至少一次全面盘点，盘盈盘亏查明原因后处理
- 处置：报废、出售须审批，收入入账

### 6.2 存货
- 入库验收、出库领用登记
- 定期盘点，做到账实相符
- 积压、滞销存货计提跌价准备

## 7. 税务管理

### 7.1 申报合规
- 按期完成增值税、企业所得税、个税、印花税等各税种申报
- 发票开具与取得符合税法规定
- 纳税资料归档备查

### 7.2 税务管理原则
- 依法纳税，合理运用税收优惠政策
- 重大涉税事项事前评估
- 关注税收政策变化，及时调整账务处理
- 严禁虚开发票、虚列成本、偷逃税款

### 7.3 发票管理
- 销项发票：按真实业务开具，严禁虚开
- 进项发票：及时认证抵扣，不合规发票退回
- 发票保管按规定年限存档

## 8. 预算管理

### 8.1 预算编制
- 流程：自上而下下达目标 → 自下而上编制 → 汇总平衡 → 审批下达
- 内容：业务预算、资本预算、财务预算
- 周期：年度预算 + 季度滚动调整

### 8.2 预算执行与考核
- 预算内支出按权限审批
- 超预算支出须专项申请
- 每月预算执行分析，偏差超 10% 说明原因
- 预算完成率纳入部门绩效考核

## 9. 财务报告与分析

### 9.1 报告体系
- 对外：法定报表（资产负债表、利润表、现金流量表）
- 对内：管理报表（经营分析、部门费用、项目利润）

### 9.2 经营分析要点
- 收入与预算对比、同比环比
- 成本费用结构分析
- 毛利、净利、现金流健康度
- 重点项目盈亏跟踪
- 风险提示与改进建议

## 10. 内部控制与风险防范

### 10.1 内控基本原则
- 不相容职务分离
- 授权审批控制
- 会计系统控制
- 财产保护控制
- 预算与运营分析控制

### 10.2 常见风险点
| 风险 | 防控措施 |
|---|---|
| 资金挪用 | 出纳与会计分离、U盾分保管、定期盘点 |
| 虚假报销 | 三单匹配、发票验真、标准控制 |
| 坏账损失 | 信用额度、账龄监控、催收机制 |
| 税务风险 | 合规申报、政策跟踪、重大事项评估 |
| 资产流失 | 定期盘点、卡片管理、处置审批 |

## 11. 审计配合与档案管理

### 11.1 审计配合
- 内部审计：按计划提供资料，落实整改
- 外部审计：配合年审、专项审计，提供底稿
- 对审计发现问题，限期整改并反馈

### 11.2 会计档案
- 凭证、账簿、报表、合同、发票按规定归档
- 保管期限按《会计档案管理办法》执行
- 借阅履行审批手续，严禁私自复印、外带

---

## 12. 财务系统与权限管理

### 12.1 系统使用
- 财务软件（ERP/账务系统）专人操作
- 按岗位分配权限，最小必要原则
- 操作留痕，定期审计权限

### 12.2 数据安全
- 重要数据定期备份
- 敏感数据（工资、客户信息）加密访问
- 离职人员即时注销系统账号
